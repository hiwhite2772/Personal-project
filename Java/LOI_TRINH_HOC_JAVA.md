# LỘ TRÌNH HỌC JAVA TỪ CƠ BẢN ĐỀN NÂNG CAO

## 📚 GIỚI THIỆU
Chào bạn! Đây là lộ trình học Java được thiết kế cho sinh viên năm 1.
Mỗi phần có lý thuyết + code mẫu + bài tập thực hành.

---

## PHẦN 1: CƠ BẢN (Tuần 1-4)

### Tuần 1: Làm quen với Java
- [ ] Cài đặt JDK và IDE (Eclipse/IntelliJ/VS Code)
- [ ] Chương trình "Hello World" đầu tiên
- [ ] Biến và kiểu dữ liệu (int, double, String, boolean)
- [ ] Nhập xuất dữ liệu (Scanner)
- [ ] Toán tử cơ bản (+, -, *, /, %)

**Bài tập thực hành:**
- Viết chương trình tính tổng 2 số
- Chương trình đổi nhiệt độ C sang F
- Tính diện tích hình chữ nhật

### Tuần 2: Cấu trúc điều khiển
- [ ] If-else
- [ ] Switch-case
- [ ] Vòng lặp for
- [ ] Vòng lặp while, do-while
- [ ] Break và continue

**Bài tập thực hành:**
- Kiểm tra số chẵn/lẻ
- Tìm số lớn nhất trong 3 số
- In bảng cửu chương
- Tính giai thừa

### Tuần 3: Mảng (Array)
- [ ] Khai báo và sử dụng mảng 1 chiều
- [ ] Duyệt mảng (for, for-each)
- [ ] Mảng 2 chiều
- [ ] Các phương thức của Arrays

**Bài tập thực hành:**
- Tìm min, max trong mảng
- Tính trung bình các phần tử
- Sắp xếp mảng
- Ma trận (cộng, nhân)

### Tuần 4: Phương thức (Method)
- [ ] Khai báo và gọi phương thức
- [ ] Tham số và return
- [ ] Phương thức static
- [ ] Overloading (nạp chồng)

**Bài tập thực hành:**
- Tạo các hàm tính toán
- Kiểm tra số nguyên tố
- Tính tổ hợp, chỉnh hợp

## PHẦN 2: TRUNG BÌNH (Tuần 5-8)

### Tuần 5-6: Lập trình hướng đối tượng (OOP) - Phần 1
- [ ] Class và Object
- [ ] Constructor (hàm khởi tạo)
- [ ] Thuộc tính (attributes)
- [ ] Phương thức (methods)
- [ ] Encapsulation (đóng gói) - getter/setter
- [ ] this keyword

**Bài tập thực hành:**
- Tạo class SinhVien (tên, tuổi, điểm)
- Tạo class HinhChuNhat (dài, rộng, tính diện tích)
- Tạo class TaiKhoanNganHang (số dư, gửi tiền, rút tiền)

### Tuần 7: OOP - Phần 2
- [ ] Kế thừa (Inheritance)
- [ ] super keyword
- [ ] Overriding (ghi đè)
- [ ] Tính đa hình (Polymorphism)
- [ ] Abstract class

**Bài tập thực hành:**
- Class NhanVien và các class con (NVFullTime, NVPartTime)
- Class HinhHoc và các hình (Tron, Vuong, CN)
- Tính lương cho các loại nhân viên

### Tuần 8: OOP - Phần 3
- [ ] Interface
- [ ] Phân biệt abstract class vs interface
- [ ] Multiple inheritance với interface
- [ ] Static và final

**Bài tập thực hành:**
- Tạo interface QuanLy cho các class
- Hệ thống quản lý thư viện
- Quản lý phương tiện giao thông

## PHẦN 3: NÂNG CAO (Tuần 9-12)

### Tuần 9: Exception Handling (Xử lý ngoại lệ)
- [ ] Try-catch-finally
- [ ] Các loại Exception
- [ ] throw và throws
- [ ] Tạo Exception tùy chỉnh

**Bài tập thực hành:**
- Xử lý lỗi chia cho 0
- Kiểm tra nhập liệu hợp lệ
- Xử lý file không tồn tại

### Tuần 10: Collections Framework
- [ ] ArrayList
- [ ] LinkedList
- [ ] HashMap
- [ ] HashSet
- [ ] So sánh các loại Collection

**Bài tập thực hành:**

- Từ điển Anh-Việt đơn giản
- Loại bỏ phần tử trùng

### Tuần 11: File I/O
- [ ] Đọc file text
- [ ] Ghi file text
- [ ] BufferedReader, BufferedWriter
- [ ] File và Path

**Bài tập thực hành:**
- Đọc/ghi danh sách sinh viên từ file
- Copy file
- Đếm số từ trong file

### Tuần 12: Nâng cao hơn
- [ ] Lambda expressions
- [ ] Stream API
- [ ] Generics cơ bản
- [ ] Multi-threading cơ bản (nếu có thời gian)

## GỢI Ý HỌC TẬP

### Mỗi ngày:
1. **Học lý thuyết**: 30-45 phút đọc và hiểu khái niệm
2. **Xem code mẫu**: 15-30 phút chạy và sửa code mẫu
3. **Làm bài tập**: 45-60 phút tự code
4. **Ôn tập**: 15 phút xem lại những gì đã học

### Lưu ý quan trọng:
- ✅ **Tự tay gõ code**, KHÔNG copy-paste
- ✅ **Chạy và test** mọi đoạn code
- ✅ **Làm bài tập** trước khi xem đáp án
- ✅ **Ghi chú** những gì chưa hiểu
- ✅ **Luyện tập mỗi ngày** (quan trọng nhất!)

### Tài nguyên học:
- W3Schools Java Tutorial
- Java Documentation (Oracle)
- GeeksforGeeks Java
- Code mẫu trong thư mục này
